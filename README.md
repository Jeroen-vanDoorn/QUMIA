Quantitative Ultrasound Muscle Imaging Analysis software

This software can be used to perform quantitative muscle ultrasound analysis.

This is version 4.0 of the software, where the core functionality is reconstructed. The previous version is findable here: https://github.com/jdoorduin/qumia.
